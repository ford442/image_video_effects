# 2026-08-15

## Deploy stopped prompting for FTP/SFTP credentials

- User: deploy always asked for FTP user/pass.
- Cause: May 30 commit `a4cb1712` removed the hardcoded DreamHost password from
  `scripts/deploy.py` / `deploy_app_only.py`. Scripts fell back to `getpass`.
- Fix: shared `scripts/deploy_credentials.py` loads gitignored `.env.deploy`
  (or `~/.config/pixelocity/deploy.env`) plus `DEPLOY_*` / `FTP_*` aliases.
  `deploy.py`, `deploy_app_only.py`, and `sync_shaders_to_1ink.py` use it.
- Local `.env.deploy` is 0600 and gitignored. This VM's `id_ed25519` was added
  to `ford442@1ink.us` `~/.ssh/authorized_keys`; BatchMode SSH now works.
- `.env.deploy.example` documents the file. Do not commit the real password.
  The old password is still the live one and was previously public in git —
  rotate when convenient.
