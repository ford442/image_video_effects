## Immutable WGSL requirements
- Standard 13 bindings: sampler, read/write textures, `Uniforms`, depth textures, data textures, extraBuffer, comparison sampler, plasmaBuffer.
- `writeTexture` must be `texture_storage_2d<rgba32float, write>`.
- `Uniforms` fields: `config`, `zoom_config`, `zoom_params`, `ripples`.
- Compute entry: `@compute @workgroup_size(16, 16, 1)`.
- Guard: `if (id.x >= u32(res.x) || id.y >= u32(res.y)) { return; }`.
- Aspect-correct UV: `(vec2<f32>(id.xy) - 0.5 * res) / res.y`.
- Mouse Y-flip for 3D coords: `-(mouse.y - 0.5)`.
- Wire `u.zoom_params.x/y/z/w` to four params.
