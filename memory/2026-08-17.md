## Black flicker fix (timestamp queries)

User reported repeating black flicker in rendering.

**Root cause:** WebGPU timestamp-query path in `WebGPUTiming.ts` (and WASM `timing.cpp`) skipped `resolveQuerySet` while `mapAsync` readback was pending. Next frames still wrote the same query indices without resolving → validation error → entire command buffer dropped → canvas clear stayed black (repeating flash).

**Secondary:** multipass compute was rewriting the same `endOfPassWriteIndex` on every intermediate pass (also illegal between resolves).

**Fix:**
1. Always resolve when timestamps were written; only gate staging copy/map on free ring slots (`stagingBusy[]`).
2. Stamp only phase starts + final compute end; intermediate multipass dispatches get no timestamp writes.
3. Same resolve-always fix in WASM `ResolveTimestampQueries`.
