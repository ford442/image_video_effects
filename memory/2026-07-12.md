# 2026-07-12 — WGSL performance/quality audit (considerations)

## Session
User asked for cross-cutting performance + quality improvements across all ~1,295 WGSL shaders (shader code or context creation).

## Key findings (prioritized for future work)

### Engine (highest ROI, affects every shader)
1. Gate `historyTex` copy — only 11 shaders use binding 13; unconditional per-frame copy wastes bandwidth
2. Reuse `extraData` Float32Array in `writeUniforms()` — per-frame alloc
3. Merge compute + blit into single command encoder where swapchain allows
4. Fix chained-slot `dataTexA` then `dataTexB` → `dataTexC` double-copy (B overwrites A)
5. Image upload `uploadRGBA8()` — CPU O(pixels) loop; use GPU blit or WASM path
6. Wire `timestamp-query` in TS render loop (allocated but unused; WASM has partial support)
7. Subgroup `-sg.wgsl` loader path dormant — 0 variant files exist

### Context / device
- `rgba32float` full pipeline = 4× bandwidth vs 8-bit; justified for sim/HDR, heavy for simple filters
- Device init solid: adapter ladder, float32-filterable, subgroups, 16-aligned scaled dims
- Blit already gamma-encodes linear→sRGB (good quality)

### Shader catalog (bulk upgrade targets)
- ~63 legacy `@workgroup_size(8,8)` vs canonical 16×16 + `WG_SIZE_X/Y` snap
- UV: many use `global_id.xy / resolution` without +0.5 pixel center (template uses center-correct)
- Aspect: hundreds reference aspect; generative subset still stretch on non-square
- Mouse: renderer flips Y (`mouseYShader = 1.0 - y`); some shaders may double-flip
- `textureSampleLevel` dominant for image filters; sims should prefer `textureLoad` for stencils
- Template entry `main_compute` vs validator requires `fn main`
- ~11 shaders opt into binding 13; rest pay history texture bind cost in layout

### Recommended execution order
1. Engine hot-path fixes (history gate, alloc reuse, dataTexC copy)
2. Mechanical shader batch: 8×8→16×16, bounds check, pixel-center UV
3. Generative quality pass: aspect-correct UV helper, ACES tone map standard
4. Subgroup variants for top-N heavy shaders OR remove dead loader branch
5. Optional: dual pipeline layout (with/without binding 13)
