# New Shader Plan: Radiant Cyber-Plasma Astro-Griffin

## Overview
A hyper-majestic, biomechanical celestial griffin woven from shattered chrono-prisms and glowing liquid-plasma, soaring elegantly through a violently shifting volumetric quantum rift while its cybernetic wings carve aural temporal fractals into the aether.

## Features
- Intricate biomechanical griffin anatomy (eagle-like forequarters, lion-like hindquarters, majestic wings) rendered entirely via raymarching SDFs.
- Liquid plasma and shattered chrono-prism textures, glowing from within.
- Dynamic, sprawling wing animation that expands, contracts, and twists organically as if traversing multidimensional currents.
- Deep, volumetric space rift background with twisting magnetic plasma streams.
- Audio-reactive bioluminescence mapping: the core and wingtips pulsate with high-frequency acoustic data, while the background rift reacts to heavy sub-bass.
- Interactive mouse gravity wells that warp the local spacetime fabric around the griffin.

## Technical Implementation
- File: public/shaders/gen-radiant-cyber-plasma-astro-griffin.wgsl
- Category: generative
- Tags: ["griffin", "plasma", "cyber", "volumetric", "fractal", "animal", "audio-reactive"]
- Algorithm: Raymarching combined with domain repetition, simplex noise warping, and multi-layered volumetric accumulation.

### Core Algorithm
The shader will employ standard raymarching (SDFs) to construct the griffin.
- Wing feathers will be defined using domain repetition (`modc`) with curved box/plane intersections to simulate overlapping, glowing crystalline plumes.
- The body will be a union of smooth-blended ellipsoids and capsules, disturbed by a 3D simplex noise function to give the shattered "chrono-prism" appearance.
- The background rift is a volumetric accumulation layer generated by stepping through multiple octaves of twisting noise space, completely bypassing the SDF hit to act as an infinite void.

### Mouse Interaction
The mouse (via `u.zoom_config.yz`) acts as a gravitational spacetime anomaly. The 3D position vector `p` is offset before SDF evaluation: `p -= vec3<f32>(mouse.x * 2.0, mouse.y * 2.0, 0.0)`. Furthermore, a twisting matrix is applied proportionally to the distance from the mouse anomaly to give a physical warp effect.

### Color Mapping / Shading
The griffin utilizes a high-contrast chromatic gradient, blending deep cyber-blues and purples at the base with blistering, high-intensity plasma golds and magentas at the wingtips.
The shading is physically based, integrating a custom sub-surface scattering approximation and strong bloom thresholds for glowing components. The audio data (`plasmaBuffer[0].x` for bass, `plasmaBuffer[1].x` for mid-highs) is used to linearly interpolate emission strength across the surface.

struct Uniforms {
    config: vec4<f32>,       // x=Time, y=Audio/ClickCount, z=ResX, w=ResY
    zoom_config: vec4<f32>,  // x=ZoomTime, y=MouseX, z=MouseY, w=Generic2
    zoom_params: vec4<f32>,  // x=Warp Intensity, y=Wing Span, z=Fractal Depth, w=Plasma Glow
    ripples: array<vec4<f32>, 50>,
};

// ... (Utility functions: rot2D, noise, smooth_min)

fn map(p: vec3<f32>) -> vec2<f32> {
    var p_warp = p;
    // Mouse warp implementation
    let mouse = u.zoom_config.yz;
    p_warp -= vec3<f32>(mouse.x * 2.0, mouse.y * 2.0, 0.0);

    // Geometry modeling...
    return vec2<f32>(1.0, 0.0);
}

fn raymarch(ro: vec3<f32>, rd: vec3<f32>) -> vec2<f32> {
    // Standard raymarching loop
    return vec2<f32>(0.0);
}

@compute @workgroup_size(16, 16, 1)
fn main(@builtin(global_invocation_id) id: vec3<u32>) {
    let dimensions = textureDimensions(writeTexture);
    if (id.x >= dimensions.x || id.y >= dimensions.y) {
        return;
    }
    let uv = vec2<f32>(f32(id.x) / f32(dimensions.x), f32(id.y) / f32(dimensions.y));

    // Core pixel calculation logic...
    textureStore(writeTexture, vec2<i32>(i32(id.x), i32(id.y)), vec4<f32>(uv, 0.0, 1.0));
}
