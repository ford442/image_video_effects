## temporal-layered-time-stamps

- **ADD: none — saturated.** Four shipped ideas; I did not invent a fifth (BRIEFS lists what I considered and why each failed the tests: still-photo outlines would vanish under motion gating; flip-through depth ≈ 2× cost; product-transmission = reimagining). `Upgraded:` NOT bumped; `Ideas:` unchanged.
- **Rescue R1 (the finding of this fork): onion outlines were a positive-feedback loop.** The ring holds this shader's own previous *outputs* (`slotDispatch.ts:204`), HEAD detected outlines on those frames, so last frame's ink was re-detected (both flanks of a thin line respond at the 1.5 px taps) and re-inked one pixel wider each frame. Real-use view: frame 6 = clean stacked outlines (intended); frame 24 = full-frame outline noise burying the picture; 40 frames `h_lay_d8.png`. Attribution run with `onionCov = 0`: stable at 60 frames, so only the outline loop diverged. The stock 1-layer-ring harness returns the live frame at every age → no feedback → the 2026-10-30 pass could not see it.
  **Fix:** outlines now come from a clean source luma ring kept in A/C: `A = (luma(live), C.r, C.g, C.b)`; next frame `C.rgba` = source luma at ages 1..4; edge = exact `textureLoad(dataTextureC)` at the sheet's own registered texel (`pc = pegUV·res`), channel `age−1`, ×1.5 to keep HEAD's 1.5 px threshold scale. The ink can never enter that ring. Cost: 3 `textureLoad` + the A write's one `textureLoad` replace HEAD's 2 filtered ring samples per age.
  **Behaviour changes, said loudly:** (a) the four newest sheets are outlined (HEAD: up to eight; sheets 5–8 still get tint/smear; default is 4 sheets so the default look is unchanged in structure); (b) outline detection is nearest-texel instead of bilinear; (c) frame 6 (HEAD still clean) differs from HEAD in 37.9 % px, mean 0.075 — mostly outline placement/strength; later frames are a different picture because HEAD is noise.
- **A packing CHANGES** (documented in the header): "display RGBA" → clean-luma history ring. HEAD never loaded C and nothing else reads this shader's A, so no consumer is affected; `writeTexture` (picture + semantic alpha) is unchanged.
- **KEEP VERBATIM (intact):** 4 params + roles, per-age spiral about the pointer, peg shift, inter-stamp smear, exponential sheet weights, hue tint, outline look (smoothstep 0.04–0.18; coverage `0.35 + 0.5·colour_intensity`), semantic alpha, ring-depth logic.
- **Tags:** `upgraded-rgba` removed (WGSL + JSON; no ACES, nothing emitted beyond range). `mouse-driven` TRUE (pointer 0.5,0.5 → 0.2,0.8: 97 % px differ — it is the spiral centre); `audio-reactive` TRUE (bass → warp, mids → saturation). No click claim, none added. JSON description now says the four newest layers are outlined from a clean luma history.
- **Checks run:** NaN 0 at 150 frames moving (stable meanL 0.228), STATIC still photo 60 frames (clean multi-hue contour copies, stable), loud audio, `echo_layers` 0 and 1 (4 and 7 sheets), warp/colour/blend at 0 and 1, D=4 / 2 / 1 (D=1 → live frame, no history, meanL 0.295). **Timing:** 40-cycle interleaved min 0.91 / p25 0.92 / paired-median 1.15 (noise); 16-cycle rounds min 1.2–1.76 under load 10–23 — expected ≤ HEAD from the sample count, re-time on a quiet box.
