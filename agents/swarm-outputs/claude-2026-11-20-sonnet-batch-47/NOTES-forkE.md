## gen-rgb-diffraction

- **Header:** `Upgraded: 2026-10-10, 2026-11-20`; `Ideas:` appended `chromatic Airy rings around the zero-order spot (§12.2F Airy disc); order-dependent spectral dispersion of the grating lobes (grating equation m·λ = d·sinθ, §12.2F)`. `Features:` unchanged. JSON: `description` appended; `features`/`params`/`x-meta` untouched.
- **KEEP VERBATIM (held):** 6-fold symmetry, hexMask, slitIntensity (freq·λ, phase offsets), SLITS loop + blaze ramp, norm/brightness, single-slit sinc² envelope, shimmer, Talbot, zero-order spot, vignette, ACES, exact-C feedback mix, all four params, audio bands. HEAD tinted lobe term kept (now reads `lobes.y`, which is exactly the HEAD scalar).
- **Idea 5 — chromatic Airy rings (`// ── Idea 5`):** `besselJ1` = Abramowitz & Stegun 9.4.4 (x ≤ 3) / 9.4.6 (x > 3), verified in numpy against a 60-term series: max |err| 3.5e-8 on 0..16 (the §12.3 F1 4-term series is wrong by ~19 at x=7; the `crystalline-veins` blend by up to 7.8e-3 at the zeros). `airyAmp = |2J1(x)/x|`. First dark ring of green at `r = 0.085` (p units); per channel `x_c = r·(3.8317/0.085)/lamRel_c` with `lamRel = (1+(λR/λG−1)·k, 1, 1+(λB/λG−1)·k)`, `k = mix(0.5,1.6,(chromAb−0.8)/1.4)` — i.e. `chromatic_spread` still widens the R/B split (default: R ×1.23, B ×0.83 of green). Two halves: (a) multiplicative — dark rings dim each channel's fringes, `mix(1−0.6·e^(−4r), 1, clamp(7.5·amp,0,1))` (centre lobe untouched); (b) additive — bright rings start at the first zero (`step(3.8317, x)`, amplitude is 0 there so no seam), `×2.0·brightness·e^(−3r)`, at the zero-order spot. Uses `radClean` = radius before the hexMask jitter so the rings are true circles. Guarded by `radClean < 1.1` (≈ half the frame); seam at the guard ≤ 0.7 %.
- **Idea 6 — order dispersion (`// ── Idea 6`):** per order m the HEAD lobe at `rm` is the green order (kept); R and B lobes at `rm·lamRel.x`, `rm·lamRel.z`, added as `(lobes.x, 0, lobes.z)·(0.30 + 0.30·treble)`. m=1 splits by ≈ ±0.025, m=4 by ≈ ±0.11 so higher orders separate and overlap (red of m=3 meets blue of m=4). Formula: grating equation (angle ∝ mλ), §12.2F row family.
- **Rescue:** two `pow(negative, 2.0)` — `exp(-pow((talbotPhase−0.5)·8, 2))` and `exp(-pow((axisRad−rm)·24, 2))` — now explicit squares. Matters more here than in the circuit because `color` goes into `dataTextureA` and the 3 % feedback mix: one NaN would persist. HEAD showed 0 NaN on the VM (SwiftShader folds it). Bit-identical where `pow` was defined.
- **A packing:** ACES display RGBA, C read as colour history with exact `textureLoad` (unchanged). Alpha `length(color)·0.6` and depth `(r+g+b)·norm·0.4` unchanged.
- **Diff vs HEAD** (512², 12 frames): defaults 49.9 % > 2/255, 27.2 % > 8/255, 2.8 % > 24/255 (a ±1–10 level wash everywhere — the lobe satellites and the ring modulation — with the visible structure concentrated in the centre). Treble 1.0, freq slider 0: 73.6 % / 51 % / 25 %. Honest read: the Airy halo around the centre is clearly findable (a clean circular ring system inside the hex-shaped bright centre, red outside blue at high spread); the order satellites are quieter than the rings at default / no audio and need treble or high chromatic spread to read as distinct bands.
- **Timing** (`mr_ab.mjs`, 512², 24 cycles × 3 rounds): p25 ratios 1.09 / 1.01 / 1.13, paired-median 1.03 / 1.02 / 1.15 → ≈1.05–1.1× HEAD. (The `min` ratios 1.10/1.50/1.35 are one lucky-low HEAD frame each; the box was loaded by sibling forks.)
- **Known, left alone (open decision for the user):** fringe spatial frequency is `freq·λ` — red tightest — which is physically inverted (fringe frequency ∝ 1/λ). It is the saved look of all six existing ideas, so it was not touched; the new ideas use the physical ordering (red outermost), so the two layers disagree about which wavelength is "bigger". Flipping it would change ~100 % of pixels.
