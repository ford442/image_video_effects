SHADER: gen-coral-reef-colony
IDENTITY (one sentence): a 2D underwater coral colony: a drifting 6x6 cell field of branch structure, a polyp grid of bright mouths, aragonite stressed-to-healthy colour, caustic light, mouse-pulled growth and click nutrient fronts.
KEEP VERBATIM: growth_speed = nutrient (with bass); polyp_size = polyp grid scale and mouth radius; color_variety = hue offset; mouse_attraction = mousePull. `aragoniteColor`, `clickFront` (age = time - ripple.z, no ripple.w), caustics, `colonyUV` drift, dla term, spawnPulse, water tint / depth attenuation, chromatic split, the existing acesToneMap (weird a/b - 0.0033 approximation: LEFT AS IS so default tone does not shift; not swapped to standard ACES), temporal blend 0.96/0.25 of prev.rgb (A.rgb stays display colour), writeTexture.a = semantic alpha. Saved params byte-exact.

SILENT BUG (fixed, disclosed): the local `fbm()` summed raw `hash21` with no interpolation, so `branchNoise` / `branchAngle` were per-pixel white noise: the "branches" were grain, and `dla` was grain too. Replaced with 5-octave value noise (smoothstep-interpolated lattice). Consequence: the default picture intentionally no longer looks like pixel static; branch orientation and the dla term are now spatially coherent. Also polyp `smoothstep(hi, lo, x)` reversed-edge calls rewritten as `1 - smoothstep(lo, hi, x)` (same curve, well-defined).

ADD (3 native ideas):
  1. Coherent forking branches - each colony cell becomes a small tree: a trunk whose angle comes from smooth cell-level noise (so neighbouring cells lean the same way, gently swaying in the existing `current`), forking at ~35 degrees into two sub-branches, half-width tapering to tips; branch mask replaces the old rotated-slab `branch`. Native: the shader already claims "branch noise" and DLA-like branching; this makes it actually branch.
  2. Skeleton accretion + bleaching memory in C.a - fed pixels (coralDensity high) accrete calcium skeleton in C.a (with a little 4-neighbour diffusion, slow erosion) that thickens the branches; where the colony later starves (pointer left, click front passed, nutrient drifted) the skeleton stays as a pale ghost that bleaches through the existing `aragoniteColor` stressed state and loses its polyps. Native: aragonite stress -> healthy colouring already exists but had no memory; precedent is crumpled-paper's ironing memory in C.a. Seed path: skeleton = 0 on frame 1 (zero-init textures), body = max(density, skel*0.5) so the shader looks identical to the no-memory look until fed. Foreign-alpha guard: stored value is skel*0.9 and reads above 0.9 are treated as 0 (stale hardcoded alpha 1.0 from a previously active shader).
  3. Star-lobed polyp mouths - polyp discs become 8-lobed anemone stars (per-cell phase, slow sway) with a dark mouth pit; lobes retract near the pointer (scaled by mouse_attraction, stronger when held) and extend with treble. Native: the polyp grid already exists; this gives each polyp an anatomy and a behaviour. Visible at audio = 0 (star shape + sway); treble only rides along.
FORBID on this file: springs / extraBuffer state, ripple shockwave stamp (clickFront already exists), IQ palette, borrowing chrono's growth-band strata / red-blue shift / budding front, any raymarching. Audio is not an idea.
A PACKING: A.rgb = display colour (ACES, temporal history read back as prev.rgb); A.a = skeleton memory (stored as skel*0.9), NOT display alpha. writeTexture.a stays the semantic alpha. Documented on the header `A packing:` line. HEAD previously stored semantic_alpha in A.a but never read it back, so the repack does not break any reader.
