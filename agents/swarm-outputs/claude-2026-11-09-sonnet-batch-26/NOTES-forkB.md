## Cost trim round (interactive-voronoi-lens only)

**Method.** Proxy = user-mode instructions of the whole SwiftShader render (`perf stat -e instructions:u`, follows the Chromium children), per frame = (I(40 frames) − I(8 frames)) / 32 at 576 px, M instr/frame; repeatable to ≈ ±2 % here (HEAD 1161–1201 over six runs). Acceptance by interleaved wall-clock (`forkB/tm.sh`, 576 px, 16 frames, A16=1, alternating order, machine otherwise idle, load 1.4–2.5, one job at a time).

**Ablation of the file as it stood (pre-trim 1950 idle / 1977 held; HEAD ≈ 1185 / 1200 → excess ≈ 765 / 777):**

| removed | idle | held | Δ idle / held |
|---|---|---|---|
| border-distance tracking (rim falls back to `cell_edge`; tracking + post-loop dead-code-eliminated) | 1550 | 1525 | **−400 / −452** |
| rim block with tracking (same DCE as above) | 1533 | 1522 | ≈ same |
| cursor-refocus DOF (4 taps) | 1768 | 1773 | −182 / −204 |

| parallax line (2 depth taps stay) | 1932 | 1938 | −18 / −39 |
| feedback push | 1931 | 1932 | −19 / −45 |

So ≈ 52 % of the excess was the border tracking, 24 % the DOF taps, 10 % the state loads; the rest is the ripple loop and two one-liners.

**What worked (the only code change besides two micro-opts):** the 3×3 loop no longer selects `m_point`, `cell_id`, `s_diff` (vec2 nested), `d2` (3 selects) per tap. It tracks `m_diff` (vec2), the lattice index `m_k` (scalar, 0..8), and the second-nearest seed with one candidate form (`cand = select(diff, m_diff, nearer)`, `candd = select(dist, m_dist, nearer)`, `s_diff = select(s_diff, cand, candd < d2)`, `d2 = min(candd, d2)`); `m_point = m_diff + f_st − m_n` and `cell_id = i_st + m_n` are rebuilt once after the loop (`m_n` decoded from `m_k`). Border tracking now costs ≈ 184 M instead of ≈ 400 M. Micro-opts: `dot(velocity, velocity) < 0.0036` instead of `length(velocity) < 0.06`, `inverseSqrt` instead of sqrt + divide in `borderDist` (identical output); the ripple loop evaluates the ring profile once (the old `shockwave()` and the neon-strength line each did `length` + `exp` on the same argument; `shockwave()` removed) — bit-identical on a two-click render (max |Δ| 0), −18 M instr on the click path. Seam grid, flat-depth identity, state texels, extremes: unchanged (below).

**Look change from the loop rewrite (stated, tiny):**
- `m_dist` / `d2` now start at 2.0 instead of 1.0 (`s_dist` is still capped at 1.0 via `min(m_dist, 1.0)`, so `cell_edge` is unchanged). In HEAD (and in my earlier file) ~0.13 % of pixels (107 of 82 944 at 288 px, default params) have no seed within 1 cell, so `cell_id`/`m_point` stayed 0: their lens was centred on the uv origin (a HEAD bug, speckle).
