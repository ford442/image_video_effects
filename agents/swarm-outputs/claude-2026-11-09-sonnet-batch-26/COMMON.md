## Known traps in this library — check each against HEAD BEFORE writing ideas
- Render HEAD first (192 AND 576 px, several T0 values, idle cursor AND moved/held cursor, audio 0 AND 0.4,0.3,0.2). If HEAD is broken (blank/black half, upside-down, strobing, NaN, early return, dead control, time-growing term, non-compiling) FIX IT and document it as RESCUE (R1, R2…), separate from ideas. A rescue that changes the default look is expected — say so with meanL/stdL before→after.
- extraBuffer[0..255] is re-uploaded ZEROED every frame: springs/envelopes/click state in extraBuffer (133..138 AND 0..132) NEVER persist, and the "single writer at (0,0)" pattern is a RACE (other threads read the zeroed value or thread (0,0)'s value depending on scheduling). In the real app the "smoothed" cursor is therefore ~(0,0)/raw/nondeterministic while minirender (persistent extraBuffer) shows it working — verify by reading, not by rendering. Fix = persistent state in A texels: texel (0,0) = state, texel (1,0) = `(fract(lastTime),0,0,0.7371)` sentinel (tol 0.001), zero/mask the C read on those texels, every thread integrates the same dt = clamp(fract(time − st1.x), 0.001, 0.05); store fract(time) (A is rgba16float on balanced/battery tiers). Reference implementations (merged on origin/main): public/shaders/chroma-kinetic.wgsl (cursor-track, header documents it; `const SENT`), cyber-ripples-coupled.wgsl (with the f16 rest-snap), gen-audio-spirograph.wgsl, cyber-lens.wgsl; and the batch-25 siblings in /root/iv-sonnet-batch-25/public/shaders/ (glass-bead-curtain.wgsl, glass-bead-curtain-iridescence.wgsl, chroma-lens-iridescence.wgsl, glass-wall-prismatic.wgsl — all use the A-texel spring; copy the pattern, not the look). If the spring is dead and not worth rescuing, REMOVE it honestly (raw mouse) and say so. Only give pointer state to a shader that already owns the pointer (all the lens shapes here do; crystal-facets / glass-brick-wall / alpha-multi-layer-glass already went raw-pointer on purpose — leave that).
- **f16 spring stall**: a spring stored in rgba16float stalls ~2e-3 short with ~0.01 residual velocity → permanent drift. Fix = rest-snap right after integration: `if all(|target−pos|<0.004) && |vel|<0.06 { pos=target; vel=0 }`. Verify with a numpy float16 round-trip if you add a spring.
- **ripples[i].w is always 0** (padding): `if (r.w > 0.0)` or scaling a click by `.w` makes every click dead. Use `r.z` (start time) + `age = time − r.z`, `rippleCount = min(u32(u.config.y), 50u)`, and bound the age (`age < ~2.5`). **`u.config.y` is the ripple COUNT** (it latches at ≥1 forever after the first click since ripples are never aged out): never use it as dt or as "a click is alive"; scan `ripples[i]` for `r.z>0 && time-r.z<window`.
- `zoom_config.x` is TIME (= config.x), not a slider; `zoom_config.w` is mouseDown (0/1). plasmaBuffer[1..] is NEVER uploaded (always 0): only plasmaBuffer[0].xyz = bass/mids/treble is live (refraction-shards reads `plasmaBuffer[3].y` / `[7].x` → dead zeros — remove or replace with live bands). extraBuffer is NOT an audio source. Never config.y or zoom_config.x as audio.
- A is rgba16float on most tiers: small per-frame deltas quantise to zero — store offsets / fract(time), flag it in NOTES. Sims seeded only at `time < 0.1` start from inherited garbage C when the shader is selected later — use the A-texel sentinel to detect "no valid state" and seed then. Feedback shaders inherit the PREVIOUS shader's C/A on a direct switch: test with `SEEDC=0.5,0.5,0.5,0.5` and `SEEDC=50,50,50,50`, and decode a display-ACES history correctly (`acesInverse(prev)/k`) or clamp it.
- Clamp before aces() (catalog ACES maps negatives to bright). Guard pow() bases (`max(x,0)`). No fwidth/dpdx in compute. No reserved identifiers (`target`, `array`, …) and none starting with `__`. No filtering sampler on rgba32float history: exact textureLoad(dataTextureC, coord, 0). Depth: non_filtering_sampler or textureLoad.
- Audio inside a time-multiplied phase (`time*(a + audio)`) teleports the pattern by time·Δaudio — use a bounded audio offset or an integrated phase. A slider-relative phase (a `fract(x*N)` where N is a slider) shifts everything when the slider moves. A hard cap that kills a slider range is a dead slider. A `fract(uv*res)`-style per-pixel mask is constant (always 0.5) — dead.
- Per-block hash noise gives a pixel mosaic at ≥512 px — use value noise; check 192 AND 576.
- Upside-down camera / camera-inside-SDF patterns: not expected here (image filters), but check the normal/viewDir are 3-D when Fresnel is claimed (batch-25's bead curtain used a 2-D normal → Fresnel ≡ 1 over half the bead).
- Timings: 4 forks render concurrently under SwiftShader so frameMs is load-noisy; re-time HEAD vs current back-to-back (2 rounds) before accepting a per-pixel cost increase; keep ≤ ~1.25× HEAD (hoist loop-invariants, share taps). fractal-glass-distort-bilateral is "Very High" complexity already — watch it.
- Mouse: keep HEAD's pointer behaviour; idle cursor (0.5,0.5) must not move the default look. No spring+ripple+IQ-palette overlay stamped on a shader that does not already own those. Every default-look claim needs a measured before/after; verify any review finding before acting.
- Do not add a second per-fork Cauchy/Fresnel/Beer–Lambert pass that merely re-implements what the file already has (the 2nd-pass files each already carry TIR / Beer–Lambert / Fresnel / dome dispersion): find a *second-order* mechanism instead.
