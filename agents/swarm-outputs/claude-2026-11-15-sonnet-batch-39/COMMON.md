If A is fed back through C as colour/state keep HEAD's documented packing; never newly introduce ACES→C→ACES, and never ACES stored sim fields. Alpha must stay semantic (never a bare `1.0` on a display store).
10. Naga-clean: no reserved identifiers (`target`, `array`, `filter`, `sample`, `ref`, `demote`, …), no swizzle assignment (`v.rgb = …`), **no `pow` with a possibly-negative base (use `x*x` / `exp`)**, no `fwidth`/`dpdx`, guard `normalize()` / divisions / `atan2(0,0)`. WGSL float `%` is TRUNCATED remainder — use `x − m·floor(x/m)` for a periodic fold. Branchless masks (`select`, `mix`) preferred. No `unpack2x16float(pack2x16float(x))`.
