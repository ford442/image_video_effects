## The failure checklist (run on EVERY file, in this order, before writing a card)

1. **Display ACES present and fed non-negative input?** (catalog ACES fit maps negatives to bright: `aces(-0.18) ≈ 0.68`.) If A stores raw sim state, never ACES the stored fields, only `writeTexture`. Photo-passthrough filters: no ACES on the photo path if it re-grades every image (batch-52 P-ACES policy) — tone-map only emitted light, clamped ≥ 0; where nothing emits, do not add an unearned `upgraded-rgba` tag. Say which you chose and why.
2. **Audio via `plasmaBuffer[0].xyz`?** If JSON claims `audio-reactive`, the WGSL must modulate something visible from `plasmaBuffer[0].xyz` (or FFT bins `extraBuffer[5..132]`, read-only). A JSON tag that is not true gets removed in the JSON (§8); a missing audio path is only added if it is native to the effect. `plasmaBuffer[1..8]` is never uploaded by the engine — never read it.
3. **`dataTextureC` read / `dataTextureA` write consistent?** A is next frame's C. If a file writes A but never loads C, say what the A write is for (downstream slot reads A as display RGBA — that is a legitimate reason, keep it). Add an exact `textureLoad(dataTextureC, coord, 0)` (clamped coord, never a sampler on rgba32float) only where a *native* idea needs one (ink bleeding into paper, a drying stroke, a latched state) and the A packing then matches how C is read. Zero-C early return (feedback that needs C≈0 never starts), state texels read as colour, alpha-as-mask read as colour = rescues.
4. **extraBuffer.** No writes to `[0..132]`. No persistent state in `[133..255]` (zeroed per frame). Reads of `[0..7]` as *parameters or fake audio* are defects.
5. **dataTextureB**: do not start using it; keep it where HEAD documents it (knitted-fabric masks, lenticular mask quad); a B write that stores zeros / unread values for no reason is hygiene noise — remove it only if nothing documented depends on it (grep `dataTextureB` / `readTexture` consumers before deleting; say what you found).
6. **Others from past batches:** `pow(negative, n)` → NaN; `ripples[i].w` is always 0; `fract(uv.x * resX)` is always 0.5 (dead masks); upside-down uv / camera inside geometry; mirrored y (mouse y is already top-down — no `1-y`); hardcoded alpha 1.0 where a semantic alpha is owed; sliders that do nothing or are shared across roles; `config.y` read as dt/audio/click count (only `min(u32(config.y), 50u)` as the ripple COUNT is legal); derivatives (`fwidth`, `dpdx`) in compute.

Fixes for defects may change the default look: do them as **rescues**, list them, say loudly if the default picture changes and by how much (pixel % + meanL). Verify a defect on HEAD first (render with the offending input varied) before fixing it.
