## tone-histogram-apply (first pass; orphan Pass 2 rescued)
**RESCUE R1 (the defect):** nothing writes `extraBuffer[1..258]` (grep `public/shaders`, `src/`; `tone-histogram` is single-pass since v2; the historical pass 1 wrote `atomic<u32>` counts this shader read as `f32`; `[0..132]` is re-uploaded every frame; the harness buffer is only 256 floats so bins 253..258 were OOB). HEAD output: exposure pinned 3.5, contrast ×~63 → binary posterised / pure white / pure black. **Fix:** in-pass histogram — `var<workgroup> wgHist: array<atomic<u32>,256>`, all 256 invocations cooperate over a fixed 32×32 stratified grid (static hash jitter, `_std` `pcg2d/u32ToUnit/hashCell22` body-identical) covering the **whole frame**, 3 barriers all in uniform control flow (no early return; `inBounds` guards only the stores); thread 0 runs HEAD's reduction (weighted mean, p05/p95, peak bin) unchanged. Every tile computes the identical integer histogram → no seams, no shimmer. No `extraBuffer` access remains.
**RESCUE R2:** contrast gain cap — `min(1/span, 3)` (HEAD `255/max(span,4)` allowed ×63 on a flat frame).
**RESCUE R3:** alpha `1.0` → `clamp(src.a,0,1)` (coverage passes through a chain).
**ADD:**
1. **Clip-limited CDF equalisation blend** (§12.2A CLAHE clip): bins clipped at 3× mean bin, excess spread uniformly (analytic `spread·(bin+0.5)` at lookup), mid-rank CDF built in the same loop; graded luma blended toward `cdf(srcLuma)` hue-preservingly (`ratio=(Lt+0.01)/(Lg+0.01)`, clamp 0..3). Amount = `0.5·Contrast` (0 ⇒ off).
2. **Percentile-anchored levels** (§12.2A): extended Reinhard `c(1+c/W²)/(1+c)` with `W = max(p95·exposure, 0.6)`; contrast span measured after that curve (`highT − lowT`, floor 0.08); pivot on the tone-mapped mean, re-anchored to Target Luma by `reach` (how much the 0.5…3.5 exposure clamp can deliver — keeps fade-to-black black); tails soft-rolled by `softEnds` (identity on [0.12,0.88], tanh roll-off outside) instead of a hard clamp.
**KEEP VERBATIM:** 4 params/roles and ranges (`mix(0.35,0.65)`, `mix(0.85,1.55)` — now × post-curve span gain —, `mix(0.80,1.55)`, hue-mode ≥ 0.5 with the `peakBin<40||>215` shift formula), `exposure = clamp(target/mean, 0.5, 3.5)`, Reinhard family, HSV saturation, bin reduction loop, depth passthrough. Deviation to be aware of: the contrast *measurement domain* changed (source span → post-curve span) and the pivot (fixed 0.5 → tone-mapped mean); the slider and its `mix(0.85,1.55)` range are intact.
**A packing:** raw stats field `(exposure/3.5, meanLuma, peakBinNorm, saturation)` — HEAD packing kept, never ACES; now real values (HEAD wrote pinned/degenerate ones). C is unread.
**No ACES / no `upgraded-rgba` tag** (Reinhard is the file's tone curve; ACES on top would double-tone-map). Features unchanged; header gained `Complexity`, `Upgraded: 2026-11-21`, `Ideas:`, `A packing:`, `Rescue:`.
**JSON:** description rewritten (behaviour changed); `params` byte-exact; additive `x-meta.upgrade.params` (none before); `multipass.prevShader: "tone-histogram"` and `multipassRegistry.ts` left alone (coordinator-owned) — the shader is now self-contained, so the chain is no longer *required* but still works.
**Results:** photo-like scenes (`apply_sheet.png`): dim scene lifted from mean 0.125 to readable, hazy scene regains contrast, highlights roll off. Target Luma 0→1: land mean 0.448→0.551, hazy 0.382→0.556, dim 0.391→0.486. Sliders all live (contrast 0↔1 changes mean 0.50→0.37, saturation, hue mode). Flat black → 0.026 (stays black), flat 0.5 → 0.489, flat white → 0.621; NaN 0. 86–100 % of pixels differ from HEAD (HEAD is garbage).
**Timing:** median **3.6×** HEAD (range 1.9–4.6, 6 interleaved rounds @256², before the one-loop merge, which is output-identical and strictly cheaper; later rounds unusable — box load 3–5× higher). Cap not meaningful: HEAD reads zeros and does ~nothing. Cost shape: 1024 cached samples + 1024 workgroup atomics + one 256-iteration serial pass **per 16×16 tile** (≈4 extra taps/pixel + ~1k serial instrs per 256 px on a GPU). If real-GPU profiling says it's heavy, cheapest trims: 2 samples/thread (512-sample histogram, p05/p95 error ≈ ±1 % rank), or run the reduction as a parallel scan.
**Gates:** precommit 2/2, naga-wasm 2/2, dead-sliders 0, extraBuffer PASS (no extraBuffer use).
